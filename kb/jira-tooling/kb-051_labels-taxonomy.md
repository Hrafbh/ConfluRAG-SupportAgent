## Summary
Règles de tagging pour améliorer la recherche et la qualité du RAG (retrieval).

## Tags recommandés (exemples)
- `login`, `sso`, `mfa`
- `mobile`, `gps`, `camera`, `pod`
- `export`, `pdf`, `csv`
- `network`, `vpn`, `proxy`
- `incident`, `runbook`, `template`

## Règles
- 3 à 6 tags maximum par page
- Tags en minuscules, sans espaces (kebab-case si nécessaire)
- Réutiliser les tags existants (éviter les doublons)

## Process
- Si une page est difficile à retrouver : ajouter 1–2 tags pertinents.
- Si un nouveau tag est nécessaire : le documenter ici et le réutiliser.

## Verification
La recherche par tag renvoie un ensemble cohérent de pages.
