## Summary
Conventions pour garder une KB lisible et facilement retrouvable (humains + RAG).

## Règles
- Titre = action + contexte (ex: “Reset MFA : perte téléphone”)
- Éviter les titres vagues (“Problème de connexion”)
- Un sujet = une page (pas de “fourre-tout”)
- Ajouter des tags/labels cohérents

## Format recommandé
- **Prefix optionnel** : How-to / Troubleshooting / Runbook / Template
- Exemple : “Troubleshooting — Exports CSV vides”

## Verification
Une recherche simple dans Confluence retrouve la page en 2–3 mots clés.
